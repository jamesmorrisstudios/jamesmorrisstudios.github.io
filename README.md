# www.jamesmorrisstudios.us

The James Morris Studios site, served by GitHub Pages from
`jamesmorrisstudios/jamesmorrisstudios.github.io`. Plain static HTML and one stylesheet,
no build step for the site itself.

## Privacy policies

`<app>-privacy-policy.html` are generated by `tools/build_privacy.py` from one template,
so the four stay consistent. Edit the script (per-app text, `UPDATED` date, contact) and run:

    python3 tools/build_privacy.py

The file names match the old site's URLs, so links from existing Google Play listings
keep working once the domain points here. The old site's content is archived in
`../jamesmorrisstudios-site-archive`.

## Going live

1. Create the repository `jamesmorrisstudios/jamesmorrisstudios.github.io` and push this.
2. Repository Settings → Pages: deploy from the `main` branch, root folder. The custom
   domain is set by the `CNAME` file (`www.jamesmorrisstudios.us`).
3. DNS for jamesmorrisstudios.us:
   - `www` CNAME → `jamesmorrisstudios.github.io`
   - apex `A` records → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
     (GitHub then redirects the bare domain to `www`)
4. Once the certificate is issued, turn on Enforce HTTPS.
5. Recommended: verify the domain for the organization (Organization settings → Pages →
   Add a domain), which adds a TXT record and stops anyone else claiming it on GitHub Pages.

Check GitHub's current Pages documentation for the DNS values before changing anything.
